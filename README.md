# SellerFlow

Private project.

## Getting Started

### Prerequisites

- Node.js 18+
- PostgreSQL 15+
- npm

### Setup

```bash
cd backend
npm install
cp .env.example .env
npx prisma generate
npx prisma migrate dev
npm run dev
```

```bash
cd frontend
npm install
cp .env.local.example .env.local
npm run dev
```
